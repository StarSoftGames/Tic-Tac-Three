# Tic-Tac-Three

A Tic-Tac-Toe variant where each player has only 3 pieces, but they can be moved around.

Based on an elementary school playground classic, the game was tipically played with sticks and acorns on top of boards carved by scratching stone benches with rocks.

## Play Online

https://starsoftgames.github.io/Tic-Tac-Three/

## Run locally

npm install  
npm run dev

## Build

npm run build  
npm run preview

## Technologies

- TypeScript
- Vite
- HTML5 Canvas
